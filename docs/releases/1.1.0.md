# AnaxiGraph 1.1.0

AnaxiGraph can now answer two questions about a change: which files use the code you plan
to edit, and which tests ran that code in a recorded pytest run.

## What changed since 1.0.0

- **Explore Python and frontend code together.** The map resolves Python imports from nested
  project roots. It also reads JavaScript and TypeScript imports, exports, top-level declarations
  and uses of those names. Type checking and path aliases remain outside the parser's scope.
- **See the effect of an edit immediately.** Preparation, inspection, plan assessment and
  validation refresh the working map as files change. The dashboard can open separate checkouts
  in different tabs.
- **Find tests from a recorded run.** Use `anaxigraph record-tests` with your project's full
  pytest run. Then use `anaxigraph tests` or the `tests_for_change` MCP tool to see the affected
  test files. The change brief estimates their share of recorded suite time. Compare the
  prediction with a full pull-request run before using it to skip tests.
  [Recording and comparison guide](https://github.com/hcekne/anaxigraph-v2/blob/v1.1.0/docs/usage.md#tests-for-a-change)
- **Carry review decisions through a change.** Relevant Pattern and architecture findings
  follow the task from planning to validation. Saved decisions survive subsequent edits, and
  check results identify the exact source snapshot they describe.

## Upgrading

For a uv tool installation, run `uv tool upgrade anaxigraph`. If you pinned the old version
in a CLI or MCP launch command, change the pin to `anaxigraph==1.1.0`. Restart running
processes, then check `anaxigraph --version`. Python 3.11 or newer is required.

The declared-input planner (`ci-plan` and MCP `ci_plan`) has been retired. Migrate those
callers to recorded test selection. For administrative tasks previously exposed through MCP,
use the CLI or dashboard for imports, workflow configuration and local usage evidence.
The local database keeps a backup during a supported schema upgrade.
[Upgrade guide](https://github.com/hcekne/anaxigraph-v2/blob/v1.1.0/docs/usage.md#upgrading-from-100)
