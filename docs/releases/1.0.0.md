# AnaxiGraph 1.0.0

1.0.0 is the stable-release candidate for replacing the legacy 0.9.x implementation in the
existing `anaxigraph` PyPI project. Publication has not yet been verified. Earlier releases remain
available; this record must be updated with actual publication evidence after release.

## Included

- One application behind the CLI, MCP, HTTP API and local dashboard.
- Python/PYI structural indexing, semantic Mapping, focused Patterns and architectural reviews,
  behavior-only Fresh Eyes alternatives, and CI/CD advice with declared-input check planning.
- Change preparation, plan assessment and validation against a pinned task baseline.
- Bounded local state and portable V2 analyses at `anaxigraph/record.json`.

JavaScript/TypeScript files are inventoried without parsed relationships. Model advice remains
proposed understanding; supplied project-check reports retain their own provenance. This release
does not restore every legacy capability.

## Breaking transition

CLI commands and MCP interfaces change. Replace old launch/plugin commands and verify actual MCP
tool calls. Local state uses `.anaxigraph-v2/knowledge.sqlite`; legacy databases and portable record
schemas have no automatic import. Back up old databases, configuration and tracked `anaxigraph/`
records before a new export. Compatible V2 portable records are reusable after input checks.

See [the upgrade guide](https://github.com/hcekne/anaxigraph-v2/blob/v1.0.0/docs/usage.md#upgrading-from-09x). Users who need a legacy workflow can
continue temporarily with `uvx --from anaxigraph==0.9.1 anaxigraph --help`, without replacing an
installed 1.0 executable.

## Install after publication

```bash
uvx --from anaxigraph==1.0.0 anaxigraph scan --repo /absolute/path/to/your/repo
uvx --from anaxigraph==1.0.0 anaxigraph serve --repo /absolute/path/to/your/repo
```

Python 3.11 or newer is required. For a persistent executable, use
`uv tool install 'anaxigraph>=1.0.0'`; update with `uv tool upgrade anaxigraph` and restart services.
