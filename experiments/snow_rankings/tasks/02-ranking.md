# Task 2 Ranking and useful travel decisions

Extend the existing app with all ranking/filtering/currency behavior in the shared contract.
Show trip costs broken into transport, accommodation and lift passes; changing trip duration must
change the relevant components. Explain confidence, unknown values and the ranking formula in
the UI. Provide a responsive geographic overview plus sortable results and a useful selected
destination panel. GBP/EUR/USD conversion must be consistent and labelled as a dated estimate.
Add regression tests, run prior checks and commit.

Acceptance focus: sorting in both directions as specified, budget/snowfall filters, totals, trip
duration, currency consistency, invalid input and useful desktop/mobile UI.
