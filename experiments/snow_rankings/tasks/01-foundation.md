# Task 1 Foundation and usable offline journey

Build a working Snow Rankings frontend/backend using the shared brief and API contract. Use the
supplied synthetic seed JSON as demonstration data with visible labels. A user can enter London
or coordinates, see representative global destinations, select a destination and inspect its daily
forecast and trip costs. Persist resort records in SQLite. Include a clean command to import a
JSON catalogue so thousands of locations do not require code changes. Add meaningful tests and
document startup, demo data and what remains unimplemented. Commit this milestone.

Acceptance focus: startup, branded page, status/catalogue/detail/search contracts, seven forecast
days, clear estimate/synthetic labels and no network requirement. Preserve the public contract.
